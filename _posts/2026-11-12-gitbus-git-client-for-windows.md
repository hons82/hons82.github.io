date: 2026-11-12

GitBus is a Windows desktop client for working with repositories on GitHub, GitLab and Gitea. It brings everyday tasks—reviewing and staging changes, committing, pushing and pulling—together with commit history, branches, tags and pull or merge requests.

It also supports Git LFS, submodules and SSH. GitBus is available for 64-bit Windows 10 and later.

Learn more and download it at [gitbus-2cadc.web.app](https://gitbus-2cadc.web.app).
